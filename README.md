# Smart Parking Management System

A console-based parking management application developed using Java, JDBC, MySQL, Object-Oriented Programming (OOP), Collections Framework, and File Handling.

The system automates parking operations by managing vehicle entry and exit, parking slot allocation, fee calculation, parking history tracking, and report generation.

## Features

* Vehicle Entry Management
* Vehicle Exit Management
* Dynamic Parking Slot Allocation
* Vehicle Search Functionality
* Parking Status Monitoring
* Automated Fee Calculation
* Parking History Tracking
* End-Day Report Generation

## Technologies Used

* Java
* JDBC
* MySQL
* Object-Oriented Programming (OOP)
* Collections Framework
* File Handling
